# STOUK-BOT
رادار عربي لاستراتيجية القاع.

الفكرة:
- التقاط السهم الذي صعد اليوم بقوة.
- مراقبته من اليوم الثاني حتى اليوم العشرين.
- السعر بين 1 و5 دولار.
- وجود صعود سابق لا يقل عن 100%.
- العودة للدعم الأصلي والثبات عدة جلسات.
- RSI دخل تحت 30 ثم بدأ بالتحسن.
- عند اكتمال الشروط تظهر خطة الدخول والوقف والأهداف.
- لا يوجد Telegram.

حد صعود جلسة اليوم مضبوط مبدئيا على 15% ويمكن تغييره في strategy.py.
