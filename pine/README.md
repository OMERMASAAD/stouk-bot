# Pivot Squeeze Pro — دليل التصميم والاستخدام

إعادة بناء كاملة لمؤشر «Smart Multi-Timeframe Pivot Squeeze Pro» بتركيز على **التصميم والخطوط والألوان** و**شارت نظيف بلا تشويش**، بهوية لونية مطابقة تمامًا لداشبورد «رادار القاع» في هذا المستودع.

| الملف | الدور |
|---|---|
| `pivot_squeeze_pro.pine` | الكود النهائي (Pine Script v5) — انسخه إلى Pine Editor ثم «إضافة إلى الشارت» |
| `design_preview.html` | معاينة بصرية للتصميم (لوحة المعلومات، بطاقات الأسعار، خطة الصفقة، مناطق المحاور) بأزرار تشغيل/إطفاء مثل مدخلات المؤشر |
| `index.html` | نفس المعاينة (نسخة مطابقة، كما هي عادة المستودع مع `dashboard_master.html`) |

## 1) الهوية البصرية

نظام ألوان واحد مستخرج من `index.html` في جذر المستودع، معرَّف مرة واحدة أعلى الملف كمتغيرات (`C_GREEN`, `C_MUTED`, …) حتى لا تتكرر الأكواد اللونية في 40 موضعًا:

| الاستخدام | اللون |
|---|---|
| خلفية اللوحة | `#0A1710` بشفافية 4% |
| رأس اللوحة | `#0E2117` |
| الحدود | `#214634` |
| نص أساسي / خافت | `#F1FFF6` / `#8FA99A` |
| إيجابي (شراء/فوق/تدفق داخل) | `#20D47B` و `#16A85F` |
| سلبي (تشبع/كسر/تدفق خارج) | `#FF5264` |
| تحذير (انضغاط/قاعدة) | `#FFC857` |
| معلومة (الفريم الأعلى) | `#7CF0D8` |
| خلايا الحالات | خلفية `#0D4D30 / #4A1A20 / #554314 / #12291E` مع نص `#6DFFB3 / #FF9AA5 / #FFD978 / #A9BBB0` |

**الخطوط والتسلسل البصري:** رأس اللوحة `size.small` بنص أبيض، التسميات في العمود الأول بلون خافت `#8FA99A`، والقيم في العمود الثاني **ملوّنة حسب الحالة** — فتُقرأ الحالة من اللون قبل النص. صف «قرار النظام» وحده يحمل تسمية بيضاء عريضة لأنه النتيجة النهائية.

## 2) ماذا تغيّر في الشارت (مقارنة بالنسخة الأصلية)

| العنصر | قبل | بعد |
|---|---|---|
| الدعم/المقاومة | خطان عريضان (linewidth 2) بلون أحمر/أخضر صارخ يمتدان على كامل التاريخ | خط رفيع (1) بألوان الهوية، + **منطقة شفافة 93%** بلا حدود بعرض `0.35×ATR` (المستوى منطقة لا رقم) |
| بطاقات الأسعار | غير موجودة (تقرأ المستوى بصريًا) | بطاقة صغيرة عند آخر شمعة فقط: «مقاومة 12.84» / «دعم 11.06» — قابلة للإطفاء |
| المرجع | لون برتقالي ثابت `color.orange` | يتلوّن حسب موقع السعر (أخضر فوق / أحمر تحت) وبشفافية أعلى حتى لا ينافس الشموع |
| الإشارة | `labelup` كبير بنص «🚀 SQUEEZE» + `barcolor` أخضر/بنفسجي دائمًا | مثلث صغير `size.small` بنص «دخول»، ودائرة صفراء لاختراق الانضغاط، و ✕ صغير أحمر للتحذير — **وتلوين الشموع متوقف افتراضيًا** |
| خطة الصفقة | غير موجودة | بطاقة واحدة عند آخر إشارة: دخول / وقف / هدف / عائد÷مخاطرة + خط وقف متقطع — تُحذف تلقائيًا عند انتهاء الإشارة |
| لوحة المعلومات | `table.new` داخل `barstate.islast` (إعادة إنشاء وميض) + إيموجي ملونة كبيرة | تُبنى **مرة واحدة** ثم تُحدَّث خلاياها، رموز أحادية العرض `▲ ▼ ◆ ○` بدل الإيموجي، 8 صفوف بمنطق واضح |
| موضع اللوحة | `table.new(position=...)` بقيمة من `input.string` (خطر عدم تجميع: يتطلب `const string`) | إنشاء بموضع ثابت + `table.set_position()` الذي يقبل قيمة متغيرة |
| الفريم الأعلى | العنوان يقول Multi-Timeframe ولا يوجد أي حساب متعدد الفريمات | `request.security` مع `lookahead_on` وقراءة `[1]` (آخر شمعة مكتملة = **بلا إعادة رسم**) |

## 3) ماذا تغيّر في المنطق

1. **الانضغاط (Squeeze) أصبح مُقاسًا فعليًا**: عرض بولنجر كنسبة مئوية من تاريخه `ta.percentrank(bbw, 20)`، والانضغاط = تحت العتبة (افتراضيًا 25%). كان الاسم في العنوان فقط.
2. **MACD أقوى**: `macdLine > signalLine and histLine > histLine[1]` (توسّع فعلي لا مجرد إشارة قديمة).
3. **فخ المطاردة أوسع**: RSI ≥ 80 **أو** امتداد السعر عن المرجع بأكثر من `2.5×ATR`.
4. **درجة الالتقاء 0–6** في اللوحة بدل حكم ثنائي.
5. **توافق Pine v5**: `ta.vwap(source, anchor)` حيث `anchor` نوعه `series bool` عبر `timeframe.change()` (نسخة نص الجلسة خاصة بـ v6)، و`label.new` بلا `border_color`/`border_width` لأنهما غير موجودين في v5.
6. **حماية البيانات**: أسهم بلا فوليوم (`ta.obv = na`) لا تُكسر الإشارة بل تظهر في اللوحة «— لا بيانات»، و`ta.vwap` على الفريم اليومي وأعلى يُستبدل بـ EMA تلقائيًا.
7. **وقف منطقي**: `min(الدعم − 0.25×ATR , الدخول − 1.5×ATR)` والهدف = `R` مضروبًا في المخاطرة.

## 4) الإعدادات الموصى بها

| الاستخدام | التوصية |
|---|---|
| أسهم منخفضة Float على فريم يومي | `pivotLen = 10`، `squeezePct = 25`، `htfTf = W` |
| تداول لحظي (15m / 1h) | `pivotLen = 8`، مرتكز VWAP = يومي، `htfTf = D`، `extMult = 2.0` |
| شارت أنظف ما يمكن | أطفئ: مناطق المحاور + خطة الصفقة + تلوين الشموع، وأبقِ بطاقات الأسعار |
| مسح بصري سريع على قائمة أسهم | أطفئ كل شيء عدا اللوحة وخطوط المستويات |

## 5) التنبيهات

خمس تنبيهات جاهزة في قائمة Alert: **إشارة دخول نظيفة** · **اختراق انضغاط** · **تحذير مطاردة** · **اختراق المقاومة الهيكلية** · **كسر الدعم الهيكلي**.
الرسائل تستخدم `{{ticker}}` و `{{interval}}`. لإضافة السعر داخل الرسالة أنشئ التنبيه من نوع *Any alert() function call* — نصوص `alertcondition` لا تقبل قيمًا متغيرة.

> ملاحظة: استخدام `request.security` مع `lookahead_on` يجعل TradingView يعرض تحذير «قد يُعاد رسمه» على المؤشر. القراءة هنا من `[1]` (آخر شمعة مكتملة في الفريم الأعلى) وهي الصيغة القياسية غير المُعيدة للرسم. إن أردت إزالة التحذير تمامًا: أطفئ «اشتراط موافقة الفريم الأعلى».

## 6) تشغيل المعاينة محليًا

cd pine && python3 -m http.server 4173 --bind 0.0.0.0
# ثم افتح http://localhost:4173/design_preview.html
